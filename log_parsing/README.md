# Log Parsing

## Description
Problème d'entretien technique : lire des lignes de log au format Nginx depuis l'entrée standard et afficher des statistiques (taille totale, codes de statut).

## Fichiers

| Fichier | Description |
|---|---|
| `0-generator.py` | Générateur de lignes de log aléatoires pour les tests |
| `0-stats.py` | Lit les logs depuis stdin et affiche les statistiques |
