# N Queens

## Description
Problème d'entretien technique classique : résoudre le problème des N reines, en plaçant N reines sur un échiquier N×N sans qu'aucune ne puisse en attaquer une autre.

## Fichiers

| Fichier | Description |
|---|---|
| `0-nqueens.py` | Résout et affiche toutes les solutions du problème des N reines |
