# Lockboxes

## Description
Problème d'entretien technique : déterminer si toutes les boîtes verrouillées d'une liste peuvent être ouvertes, sachant que chaque boîte peut contenir des clés vers d'autres boîtes.

## Fichiers

| Fichier | Description |
|---|---|
| `0-lockboxes.py` | Fonction `canUnlockAll` déterminant si toutes les boîtes peuvent être ouvertes |
| `main.py` | Fichier de test |
