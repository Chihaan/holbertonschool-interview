# Star Wars API

## Description
Problème d'entretien technique : interroger la Star Wars API (SWAPI) en JavaScript/Node.js pour récupérer les personnages apparaissant dans un film donné.

## Fichiers

| Fichier | Description |
|---|---|
| `0-starwars_characters.js` | Script affichant les personnages d'un film Star Wars via l'API |
| `package.json` / `package-lock.json` | Dépendances Node.js du projet |
